# HaloCE-Arena-Evolved-Open-CE-Nucleus-coop-handler
A simple handler for HaloCE Arena Evolved/OpenCE,for multiple display, perfect for Lan party

AI vibecoded with Gemini with some tweaks

### Setup & Input Lock
1. Drag your controllers, keyboards, and mice onto either display in Nucleus Co-Op (up to 4 per display) and click **Play**.
2. Once all windows finish opening and resizing, press the **END** key once to lock inputs to each screen (press **END** again to unlock when finished).

### Hosting the Match (Player 1 / Display 1)
1. Go to **Multiplayer > Host Game**.
2. Set the Network type to **LAN**.
   > **Note:** Switching to LAN may temporarily disconnect other players in the party due to a unknown game bug. Simply back out and select **Host Game** again to resolve it.
3. Click **Start Server**.

### Joining the Match (All Other Instances / Display 2)
1. Go to **Multiplayer > Join LAN**.
2. Select the local server created by Player 1.
3. Have fun!
